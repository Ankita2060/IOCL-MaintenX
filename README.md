MaintenX: AI-Powered Predictive Maintenance System
An AI-based predictive maintenance system designed to monitor industrial machine health and predict potential machine failures using Machine Learning.

Project Overview

MaintenX is a web-based predictive maintenance application that uses machine learning to analyze industrial equipment parameters and estimate the possibility of machine failure.
The system helps users identify potential equipment problems before breakdowns occur, supporting timely maintenance decisions, reducing unexpected downtime, and improving operational efficiency.

Key Features

Machine Failure Prediction: Predicts whether a machine is likely to experience failure using a trained Random Forest model.
Machine Health Monitoring: Displays machine health scores and condition indicators.
Failure Risk Analysis: Shows failure probability and categorizes machine risk.
Maintenance Recommendations: Provides recommendations based on prediction results.
CSV Batch Prediction: Allows users to upload CSV files for multiple machine predictions.
Prediction History: Stores previous prediction records using SQLite.
Interactive Dashboard: Displays machine statistics and visual analytics.
PDF Report Generation: Generates downloadable prediction reports.
